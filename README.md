---

### 🌟 Brand Overview & Key Differentiators
1. **Instantly Oil & Waterproof on Day 1**: Powered by physician-formulated NovaLash molecular bond technology. No 24-48 hour wait; clients can cry, shower, swim, or exercise immediately.
2. **4-Week Retention Guarantee**: High-retention isolation requiring only once-a-month touchups, saving clients thousands annually over standard 2-week salon fills.
3. **The Life is Suite™ Complimentary Candy Bar**: The first-ever lash salon with a dedicated international candy bar featuring imported Swiss truffles, German sour confections, Swedish berry gummies, and chilled San Pellegrino.
4. **Master Lash Credentials & Celebrity Portfolio**: Sophia Navarro is the NovaLash VP of Global Education, creator of the NovaLash Technique and American Volume™ technique, and trusted lash artist to global icons including Beyoncé Knowles.
5. **Doctor-Reviewed Optometric Safety**: Staff undergoes periodic continuing education with Doctors of Optometry; strictly enforces refusal protocols for active ocular inflammation; uses autoclave-sterilized micro forceps.

### 🚀 Production Deployment Instructions

#### 1. Quick Local Development
```bash
# Install dependencies
npm install

# Start Vite development server on port 3000
npm run dev
```

#### 2. Production Static Build
```bash
# Compile optimized production assets to /dist
npm run build

# Preview production build locally
npm run preview
```

#### 3. Deploying to Cloud Run / Vercel / Netlify / GitHub Pages
- **Output Directory**: `dist`
- **Build Command**: `npm run build`
- **Node Version**: 18+ (tested on Node 20 / 22)
- All navigation uses client-side hash routing (`#home`, `#about`, `#services`, etc.), making it 100% compatible with static file hosts and CDN edge networks without requiring custom redirect rewrites.
